# MÓDULO 3.1: Ingestor y Parser de Archivos Estructurados (MusicXML y MIDI)
# Archivo: tasks/phase-03/3.1-structured-ingestion.md — Nivel 3 (Micro-tareas Atómicas)

Este módulo implementa el pipeline de conversión de archivos estructurados estándar (MusicXML y MIDI) hacia los modelos de dominio Pydantic (`Score`, `Measure`, `Note`, `ChordSymbol`), calculando automáticamente las sílabas de solfeo latino (`do`, `re`, `mi`...) y las alteraciones para el renderizado didáctico.

---

## Micro-tareas

- [x] **3.1.1: Parser de MusicXML hacia modelo Pydantic `Score` con inyección de solfeo latino.**
  - **Archivos:** `backend/app/services/musicxml_parser.py`, `backend/tests/test_musicxml_parser.py`
  - **BDD:** Given un XML MusicXML (single staff o grand staff), When se procesa con `parse_musicxml_content`, Then extrae armaduras, compases, notas con duración y calcula automáticamente la sílaba de solfeo (`do`, `re`, `mi`...) y el texto para la cápsula didáctica (ej. `♭si`, `mi`).
  - **Comando de Test:** `PYTHONPATH=backend backend/.venv/bin/pytest backend/tests/test_musicxml_parser.py`

- [x] **3.1.2: Parser e ingestor de archivos MIDI hacia modelo de dominio `Score`.**
  - **Archivos:** `backend/app/services/midi_parser.py`, `backend/tests/test_midi_parser.py`
  - **BDD:** Given un archivo MIDI binario estándar, When se procesa con `parse_midi_bytes`, Then cuantiza rítmicamente las notas y genera un objeto `Score` válido con clave y compases.
  - **Comando de Test:** `PYTHONPATH=backend backend/.venv/bin/pytest backend/tests/test_midi_parser.py`

- [>] **3.1.3: Análisis armónico asistido con `music21` para inferencia de acordes en piano.**
  - **Archivos:** `backend/app/services/harmonic_analysis.py`, `backend/tests/test_harmonic_analysis.py`
  - **BDD:** Given notas polifónicas en ambas manos de un compás, When se ejecuta el análisis armónico, Then infiere el acorde fundamental y añade objetos `ChordSymbol` con formato latino (`Si♭7`, `Dom`) y americano (`B♭7`, `Cm`).
  - **Comando de Test:** `PYTHONPATH=backend backend/.venv/bin/pytest backend/tests/test_harmonic_analysis.py`
