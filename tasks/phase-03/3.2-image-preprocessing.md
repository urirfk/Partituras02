# MÓDULO 3.2: Pipeline de Preprocesamiento de Imagen con OpenCV
# Archivo: tasks/phase-03/3.2-image-preprocessing.md — Nivel 3 (Micro-tareas Atómicas)

Este módulo implementa el pipeline de visión artificial y preprocesamiento de imágenes musicales escaneadas o fotografiadas: binarización adaptativa limpia (eliminación de sombras y arrugas), corrección de inclinación (*deskewing*) mediante detección de líneas de pentagrama, y conversión de PDFs mono/multipágina.

---

## Micro-tareas

- [x] **3.2.1: Implementar binarización adaptativa y normalización de contraste con OpenCV.**
  - **Archivos:** `backend/app/services/image_preprocessor.py`, `backend/tests/test_image_preprocessor.py`
  - **BDD:** Given una imagen RGB/grises con iluminación no uniforme o sombras, When se aplica `preprocess_image_bytes`, Then genera una imagen binarizada nítida en blanco y negro puro (255 fondo, 0 tinta).
  - **Comando de Test:** `PYTHONPATH=backend backend/.venv/bin/pytest backend/tests/test_image_preprocessor.py`

- [x] **3.2.2: Implementar algoritmo de corrección de inclinación (*Deskewing*) con Transformada de Hough.**
  - **Archivos:** `backend/app/services/image_preprocessor.py`, `backend/tests/test_image_preprocessor.py`
  - **BDD:** Given una imagen con inclinación angular (hasta ±15°), When se procesa con `deskew_image`, Then calcula el ángulo dominante de los pentagramas y rota la imagen a la horizontal exacta (0°).
  - **Comando de Test:** `PYTHONPATH=backend backend/.venv/bin/pytest backend/tests/test_image_preprocessor.py`

- [x] **3.2.3: Ingestor y conversor de PDFs mono y multipágina a páginas procesadas.**
  - **Archivos:** `backend/app/services/pdf_converter.py`, `backend/tests/test_pdf_converter.py`
  - **BDD:** Given un archivo PDF con partituras de 1 o más páginas, When se ejecuta `convert_pdf_to_images`, Then extrae cada página como flujo de imagen procesado listo para el motor OMR.
  - **Comando de Test:** `PYTHONPATH=backend backend/.venv/bin/pytest backend/tests/test_pdf_converter.py`
