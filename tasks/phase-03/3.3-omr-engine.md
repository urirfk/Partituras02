# MÓDULO 3.3: Motor de Inferencia OMR y Mapeo a Estructura Musical Canónica
# Archivo: tasks/phase-03/3.3-omr-engine.md — Nivel 3 (Micro-tareas Atómicas)

Este módulo implementa el motor de reconocimiento óptico de música (OMR): detección robusta de pentagramas y compases mediante visión por computador (*StaffDetector*) y abstracción unificada (*OmrEngine*) para convertir páginas escaneadas en partituras didácticas `ScoreSchema` con solfeo latino y armonía asistida.

---

## Micro-tareas

- [x] **3.3.1: Implementar detector de pentagramas, líneas y compases con OpenCV (*StaffDetector*).**
  - **Archivos:** `backend/app/services/staff_detector.py`, `backend/tests/test_staff_detector.py`
  - **BDD:** Given una imagen binarizada de partitura, When se procesa con `detect_staves_and_measures`, Then segmenta los sistemas, calcula el espaciado interlineal (*line_spacing*), localiza las 5 líneas de cada pentagrama y las coordenadas X de las barras de compás.
  - **Comando de Test:** `PYTHONPATH=backend backend/.venv/bin/pytest backend/tests/test_staff_detector.py`

- [x] **3.3.2: Implementar pipeline unificado de extracción OMR (*OmrEngine*) y mapeo a `ScoreSchema`.**
  - **Archivos:** `backend/app/services/omr_engine.py`, `backend/tests/test_omr_engine.py`
  - **BDD:** Given una imagen o páginas procesadas, When se invoca `process_omr_image`, Then orquesta la extracción musical, inyecta solfeo latino y análisis armónico, devolviendo un modelo `ScoreSchema` completo.
  - **Comando de Test:** `PYTHONPATH=backend backend/.venv/bin/pytest backend/tests/test_omr_engine.py`
