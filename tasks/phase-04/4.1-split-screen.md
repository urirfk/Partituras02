# MÓDULO 4.1: Interfaz Split-Screen Zen con Divisor Dinámico Ajustable y Vista Dual
# Archivo: tasks/phase-04/4.1-split-screen.md — Nivel 3 (Micro-tareas Atómicas)

Este módulo implementa el contenedor Split-Screen: un divisor horizontal/vertical arrastrable mediante ratón o gestos táctiles que separa la partitura escaneada original del lienzo didáctico vectorial SVG, con botones rápidos de colapso (*Sólo Original*, *Dividido*, *Sólo Didáctico*).
