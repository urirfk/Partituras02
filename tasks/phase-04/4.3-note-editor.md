# MÓDULO 4.3: Editor Asistido Popover por Clic en Nota y Sistema Undo/Redo
# Archivo: tasks/phase-04/4.3-note-editor.md — Nivel 3 (Micro-tareas Atómicas)

Este módulo implementa el editor asistido en el lienzo: permite al usuario hacer clic o tap sobre cualquier nota musical para desplegar un Popover contextual de corrección rápida (altura de nota, alteración, digitación 1-5, letra) respaldado por un historial de mutaciones Undo/Redo para revertir cualquier cambio.
