# MÓDULO 5.1: Exportador PDF Vectorial A4 1:1 y Diálogo de Descarga
# Archivo: tasks/phase-05/5.1-pdf-export.md — Nivel 3 (Micro-tareas Atómicas)

Este módulo implementa el motor de exportación vectorial a documento PDF estándar A4 para impresión física de partituras didácticas, así como el diálogo modal de configuración de salida (orientación, márgenes, título editorial).

---

## Micro-tareas

- [x] **5.1.1: Implementar servicio de exportación PDF vectorial (`pdfExporter.ts`, `pdfExporter.test.ts`).**
  - **Archivos:** `frontend/src/services/pdfExporter.ts`, `frontend/src/services/pdfExporter.test.ts`
  - **BDD:** Given una partitura con N sistemas renderizados en elementos SVG, When se invoca `exportScoreToPdf`, Then crea un documento PDF A4 vectorial con paginación limpia, márgenes configurables y cabecera editorial (título/compositor) sin pixelación ni rasterizado destructivo.
  - **Comando de Test:** `npm --prefix frontend run test -- src/services/pdfExporter.test.ts`

- [>] **5.1.2: Implementar diálogo de configuración `PdfExportModal.tsx` e integración en `App.tsx`.**
  - **Archivos:** `frontend/src/components/export/PdfExportModal.tsx`, `frontend/src/components/export/PdfExportModal.test.tsx`, `frontend/src/App.tsx`, `frontend/src/locales/es.json`, `frontend/src/locales/en.json`
  - **BDD:** Given el lienzo de partitura activa, When el usuario pulsa el botón de exportación PDF, Then se abre un modal accesible con opciones de orientación (Vertical/Horizontal), márgenes y título, permitiendo generar y descargar el archivo `.pdf` con retroalimentación visual de progreso.
  - **Comando de Test:** `npm --prefix frontend run test -- src/components/export/PdfExportModal.test.tsx`
