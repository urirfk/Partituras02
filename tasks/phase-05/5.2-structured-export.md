# MÓDULO 5.2: Exportadores Estructurados (MusicXML, MIDI y Proyecto Local .partitura)
# Archivo: tasks/phase-05/5.2-structured-export.md — Nivel 3 (Micro-tareas Atómicas)

Este módulo implementa la persistencia y exportación estructurada de partituras didácticas: formato de sesión nativo `.partitura` (JSON serializado con partitura, configuraciones ortogonales y metadatos), exportador estándar MusicXML 3.1/4.0 y generador de archivos MIDI estándar para reproducción externa.

---

## Micro-tareas

- [x] **5.2.1: Implementar formato de sesión y serializador local `.partitura` (`projectSession.ts`, `projectSession.test.ts`).**
  - **Archivos:** `frontend/src/services/projectSession.ts`, `frontend/src/services/projectSession.test.ts`
  - **BDD:** Given una partitura editada y sus configuraciones didácticas activas, When el usuario guarda la sesión, Then genera un archivo `.partitura` JSON validado con versión de esquema, y permite su restauración exacta (simetría de lectura/escritura).
  - **Comando de Test:** `npm --prefix frontend run test -- src/services/projectSession.test.ts`

- [x] **5.2.2: Implementar endpoints de exportación MusicXML y MIDI en backend y cliente frontend (`export_service.py`, `structuredExporter.ts`).**
  - **Archivos:** `backend/app/services/export_service.py`, `backend/app/api/endpoints/export.py`, `backend/tests/test_api_export.py`, `frontend/src/services/structuredExporter.ts`, `frontend/src/services/structuredExporter.test.ts`
  - **BDD:** Given una partitura `ScoreSchema` canónica, When se solicita exportar a MusicXML o MIDI, Then genera un documento MusicXML válido o archivo MIDI estándar con duraciones, notas, alteraciones y cifrados armónicos intactos.
  - **Comando de Test:** `backend/.venv/bin/pytest backend/tests/test_api_export.py && npm --prefix frontend run test -- src/services/structuredExporter.test.ts`

  - **BDD:** Given la interfaz principal, When el usuario despliega las opciones de exportación estructurada, Then puede descargar `.partitura`, `.musicxml` o `.mid`, y cargar archivos `.partitura` preexistentes restaurando el estado completo de la sesión.
