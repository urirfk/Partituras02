# MÓDULO 6.1: Suite de Integración End-to-End y Pruebas de Invarianza Ortogonal
# Archivo: tasks/phase-06/6.1-e2e-testing.md — Nivel 3 (Micro-tareas Atómicas)

Este módulo implementa la suite completa de pruebas integradas extremo a extremo (E2E) simulando los flujos de usuario reales: carga/ingesta de partitura, edición interactiva de notas con historial de deshacer/rehacer, verificación estricta de invarianza ortogonal ante cambios dinámicos de controles didácticos, y ciclo de vida de exportación e intercambio de sesiones.

---

## Micro-tareas

- [x] **6.1.1: Suite de integración E2E del flujo de carga, edición interactiva y Deshacer/Rehacer.**
  - **Archivos:** `frontend/src/tests/e2e/workflowIntegration.test.tsx`
  - **BDD:** Given la aplicación con una partitura cargada, When el usuario hace clic en una nota, modifica su alteración o digitación en el popover, y luego presiona Undo (Ctrl+Z) y Redo (Ctrl+Y), Then la representación visual SVG y la estructura musical se actualizan fielmente en cada paso manteniendo la sincronía rítmica y vertical.
  - **Comando de Test:** `npm --prefix frontend run test -- src/tests/e2e/workflowIntegration.test.tsx`

- [>] **6.1.2: Suite de integración E2E de invarianza ortogonal estricta de controles didácticos.**
  - **Archivos:** `frontend/src/tests/e2e/orthogonalInvariance.test.tsx`
  - **BDD:** Given una partitura renderizada en el lienzo con modificaciones de notas, When el usuario conmuta alternativamente los 8 controles (solfeo, alteraciones en cápsulas, acordes, digitaciones, letra, densidad, escala, transposición), Then cada control modifica únicamente su capa visual correspondiente sin alterar el valor de los otros 7 controles ni resetear las notas editadas.
  - **Comando de Test:** `npm --prefix frontend run test -- src/tests/e2e/orthogonalInvariance.test.tsx`

- [ ] **6.1.3: Suite de integración E2E de ciclo de sesión (.partitura) y exportaciones múltiples.**
  - **Archivos:** `frontend/src/tests/e2e/sessionAndExportWorkflow.test.tsx`
  - **BDD:** Given una partitura personalizada con configuraciones didácticas específicas, When el usuario descarga la sesión en `.partitura` y la vuelve a importar, o genera exportaciones PDF / MusicXML / MIDI, Then la sesión se reconstituye al 100% idéntica y los payloads de exportación contienen la notación y configuraciones exactas.
  - **Comando de Test:** `npm --prefix frontend run test -- src/tests/e2e/sessionAndExportWorkflow.test.tsx`
