# MÓDULO 6.2: Refinamiento Visual Zen, Accesibilidad y Adaptabilidad Responsive
# Archivo: tasks/phase-06/6.2-visual-refinement.md — Nivel 3 (Micro-tareas Atómicas)

Este módulo pule la experiencia estética y pedagógica Zen de la aplicación: asegura contraste óptimo WCAG AAA para lectura en atriles y partituras en papel, perfecciona la coherencia de temas (Claro, Oscuro y Modo Atril Cálido con persistencia en `localStorage`), asegura adaptabilidad responsive y ergonomía táctil en tablets y móviles, e implementa navegación accesible ARIA y atajos de teclado completos.

---

## Micro-tareas

- [x] **6.2.1: Sistema de Tema Global (Claro / Oscuro), persistencia y contraste didáctico.**
  - **Archivos:** `frontend/src/context/ThemeContext.tsx`, `frontend/src/context/useTheme.ts`, `frontend/src/context/ThemeContext.test.tsx`, `frontend/src/App.tsx`, `frontend/src/locales/es.json`, `frontend/src/locales/en.json`
  - **BDD:** Given la aplicación en cualquier vista, When el usuario cambia entre modo Claro y Oscuro mediante el botón de tema en la cabecera, Then las clases `dark` se aplican consistentemente a la raíz del documento, la preferencia se almacena en `localStorage`, y los contrastes visuales de las cápsulas y el pentagrama cumplen estándares de legibilidad.
  - **Comando de Test:** `npm --prefix frontend run test -- src/context/ThemeContext.test.tsx`

- [x] **6.2.2: Adaptabilidad Responsive y Ergonomía Táctil en Barra de Controles y Split-Screen.**
  - **Archivos:** `frontend/src/components/controls/OrthogonalControlsBar.tsx`, `frontend/src/components/layout/SplitScreenLayout.tsx`, `frontend/src/tests/e2e/responsiveLayout.test.tsx`
  - **BDD:** Given una pantalla de tablet o móvil (viewport angosto), When el usuario interactúa con la barra ortogonal y el split-screen, Then los controles se reorganizan fluidamente sin desbordamiento horizontal y el panel táctil permite colapsar o redimensionar las vistas con gestos fluidos.
  - **Comando de Test:** `npm --prefix frontend run test -- src/tests/e2e/responsiveLayout.test.tsx`

- [>] **6.2.3: Accesibilidad ARIA, Focus Management y Navegación por Teclado.**
  - **Archivos:** `frontend/src/components/controls/OrthogonalControlsBar.tsx`, `frontend/src/components/editor/NoteEditPopover.tsx`, `frontend/src/components/export/PdfExportModal.tsx`, `frontend/src/tests/e2e/accessibilityAria.test.tsx`
  - **BDD:** Given un usuario que navega exclusivamente mediante teclado o lector de pantalla, When recorre la barra de herramientas, modales y popovers con Tab/Shift+Tab y Enter/Espacio, Then el foco queda contenido (focus trap) y todos los elementos interactivos cuentan con roles y descripciones ARIA internacionalizadas.
  - **Comando de Test:** `npm --prefix frontend run test -- src/tests/e2e/accessibilityAria.test.tsx`
